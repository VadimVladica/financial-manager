# Financial Manager

A simple console-based financial manager written in Python.

## About

This project helps users track their income, expenses, and current balance.

## Features

- Add income
- Add expenses
- View current balance
- Validate positive amounts
- Handle unknown commands
- Exit the program

## Requirements

- Python 3

## How to Run

Run the program from your terminal:

```bash
python main.py
```

If your system uses `python3`, run `python3 main.py` instead.

## Limitations

- Data is stored in memory and is lost when the program exits.
- Invalid text input for amounts is not handled yet.
